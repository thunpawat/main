# Canvas art

A generated art piece, following the same pattern as `profile/`, `todo/`,
and `expenses/` — a standalone addition to this fork used as a personal
site repo, independent of the docs app.

## Contents

* `design-philosophy.md` — "Quiet Taxonomy," a short design-philosophy
  statement (an aesthetic movement, not a layout spec) written before the
  piece itself, per the design process this was built with.
* `quiet-taxonomy.png` / `quiet-taxonomy.pdf` — the finished piece: a single
  18-by-24-inch plate in the style of a herbarium specimen sheet, built as
  static HTML and SVG (original, generated line art — no external images)
  and rendered with Chromium. Nothing in this directory needs a build step;
  the two files are the deliverable.

## Design note

The piece treats small, ordinary personal record-keeping — the kind of
thing `todo/` and `expenses/` exist to hold — as if it were pressed and
catalogued specimens on a naturalist's plate. The connection is meant to be
felt rather than read; nothing on the sheet names it directly.
