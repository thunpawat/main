# Personal profile page

`index.html` is a standalone, self-contained personal profile page for Thunpawat
Techarsoontornsakun (Maggi) — Marketing & Digital Strategy Consultant. It has no
build dependency on the rest of this repository (which is a fork of
[github/docs](https://github.com/github/docs)); open the file directly in a
browser, or serve `profile/` as a static site (e.g. via GitHub Pages) to publish it.

Content is sourced from the attached CV and certifications (PMP, Google Partner,
Meta Ads, Certified Scrum Master, Claude 101, Canva Essentials). A home postal
address was intentionally left off the public page; email and phone are included
as public contact points.
