# Personal profile page

`index.html` is a standalone, self-contained personal profile page for Thunpawat
Techasoontornsakun (Maggi) — Marketing & Digital Strategy Consultant. It has no
build dependency on the rest of this repository (which is a fork of
[github/docs](https://github.com/github/docs)); open the file directly in a
browser, or serve `profile/` as a static site (e.g. via GitHub Pages) to publish it.

Content is sourced from the attached CV, certifications (PMP, Project
Management Essentials, Google Partner, Meta Ads, Certified Scrum Master,
Claude 101, Canva Essentials), and a supplied list of selected work — brands
(Say Ohh!, Zecret Spoon, Pai Linn, Fresh O', Fresh O' Gold) and events
(THAIFEX–Anuga Asia, IMPACT).

Legal name spelling was confirmed against a government ID; no ID number, date
of birth, home address, or photo from that document is included anywhere in
this page or repo. A home postal address from the CV was intentionally left
off the public page.

The "References & assets" section links to Google Drive folders and Google
Photos albums. These were included at the profile owner's explicit request;
note that anyone who opens the page can follow them, so their contents are
effectively public.
